# Dev Full Cycle - Desafio CI/CD

Aplicacao simples em Node.js com uma calculadora de operacoes basicas.

## Requisitos

- Node.js 18+ ou superior

## Como executar

```bash
npm start
```

## Estrutura inicial

- `src/calculator.js`: funcoes de soma, subtracao, multiplicacao e divisao
- `src/index.js`: ponto de entrada com demonstracao simples no terminal
